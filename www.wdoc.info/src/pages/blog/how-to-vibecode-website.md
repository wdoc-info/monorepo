## The domain

Every website starts with a **domain name** — your storefront on the internet.

A domain is like the **name of a town**: it tells Google, OpenAI, and everyone else _roughly_ where your content lives.  
For this website, the domain is **wdoc.info**.

To buy a domain, you have several popular options:

- [Namecheap](https://www.namecheap.com/)
- [Cloudflare Registrar](https://www.cloudflare.com/fr-fr/products/registrar/) — recommended for beginners
- [AWS Route53](https://aws.amazon.com/fr/route53/) — powerful, but overkill when starting out

Personally, I use Route53 because my other projects run on AWS, but it’s not the most beginner-friendly.  
Cloudflare is cheap, simple, and offers great features once you level up.

## The storage

Once you have a domain, you need a **place to store your website files**.

Since this project is an open source format, the simplest option is [GitHub pages](https://docs.github.com/fr/pages).  
GitHub hosts your code publicly and uses **Git**, which is a version control system. Think of Git as a time machine that stores the history of every change you make.

GitHub Pages then takes your static files and publishes them to the web automatically.

This website is stored [here](https://github.com/wdoc-info/wdoc-www). It looks intimidating but don't worry we will start simple.
